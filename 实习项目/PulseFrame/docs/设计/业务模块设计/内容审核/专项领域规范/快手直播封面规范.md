# 快手直播封面规范

> 来源：https://www.kuaishou.com/norm?tab=liveCover
> 抓取日期：2026-11-12
> 说明：从页面公开 HTML 提取。

良好的封面可以表达直播的主题，获得平台更多的推荐及曝光，吸引更多观众观看你的直播。
快手不鼓励怎样的直播封面?
一、直播封面标题使用不当，引导性强。
传达消极、厌世等不良情绪，营造卖惨人设；
突出单身离异等形象，表达不恰当的交友倾向。
二、直播封面中存在着装不当的画面，或展示易引发联想的姿势或动作
穿着紧身、透视、超短裙等服饰，刻意暴露或凸显身体轮廓；
展示未成年人不当着装或，不利于未成年人保护的内容。
三、直播封面中展示易引发性联想的文字、物品、场景、人物或不雅场所
使用易引发暧昧联想的文字，如:宾馆见；
展示性相关的物品、场所、人物等。
四、直播封面中含有可能影响观看体验的内容
展示非主流恋情、炒作纠纷等不符合传统生活习惯的内容；
封面中出现其他平台的名称、水印、贴纸、特效或剪辑界面。
展示奇装异服、拜金炫富等不符合主流价值观的内容；
展示夸张吃播、血腥画面、事故现场等可能引人不适的内容。
快手鼓励怎样的直播封面?
一、封面清晰美观，比例适当，无拉伸和变形，具有可看性；
二、封面传达的价值观积极向上，风格干净明亮，整体给人美感；
三、封面主体突出，脸部特征明显，人物举止舒适，形象真诚友善；
四、封面包含直播的关键信息，或使用有吸引力的关键词，整体内容切合直播主题。
常见问题
1. 直播封面质量不佳会怎样?
答:如果直播封面质量不佳，可能会影响直播间人气，优质的直播封面可以获得平台更多曝光哦。
2. 收到“直播封面优化提示”的私信，我违规了吗?
答:并没有违规，当您收到直播封面优化提示的私信时，意味着您的直播封面还有可以提升的空间，您可以根据调整建议改进后重新上传。
3. 直播封面违规了会怎样?
答:快手严格禁止直播封面中含有不符合国家法律法规及快手直播规范的内容，如果直播封面存在违规内容，平台会依据情节严重程度给予直播封面清空、直播权限封禁、账号封禁等处罚，所以一定要规范上传封面哦。
