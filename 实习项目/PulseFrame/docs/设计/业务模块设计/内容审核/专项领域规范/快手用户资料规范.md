# 快手用户资料规范

> 来源：https://www.kuaishou.com/norm?tab=userInfo
> 抓取日期：2026-11-12
> 说明：从页面公开 HTML 提取。

一、用户资料包括哪些内容？
用户昵称、个人简介、用户头像、背景图片
二、平台不鼓励什么样的用户资料？
1、含有违法违规、封建迷信、传销诈骗、赌博枪支等内容，如网络博彩、传销代理广告等；
2、含有色情低俗内容，如色情交易交友网站、二维码、低俗擦边的文字、段子、图片、资源等；
3、含有引导他人至站外平台，或宣传推广第三方平台的内容，如二维码、水印、标识等；
4、含有影响未成年人身心健康成长的不良信息；
5、含有侵犯他人权益的内容，如曝光隐私、谩骂他人、恶搞他人头像等；
6、含有诱导营销类的内容，如：以金钱、实物或虚拟奖品，诱导用户关注互动、完成任务或引导至站外平台；
7、含有血腥暴力、自残自杀、低级趣味等易引发观感不适的内容；
8、含有影响平台秩序的内容，如仿冒快手官方账号或人员、仿冒明星或公众人物等；
9、含有违规广告信息，如推广销售假冒伪劣产品，推广游戏代练、道具买卖等服务，推广无版权的影视资源、违规发布兼职创业信息等；
10、电商主播的用户资料中出现联系方式，如:手机号、微信号、二维码、变体的联系方式(V我/主页有微/主页有惊喜等)或第三方平台账号、昵称等内容。
三、不符合规范的用户资料会如何处理？
1、当您的昵称/头像/个人简介/背景图片出现不良信息时，会被重置清空；
2、若违规程度较严重，您的昵称/头像/个人简介/背景图片的修改功能还会被封禁，封禁到期后才可以重新上传更新。
四、什么是优质的用户资料？
用户资料是展示自我的一个窗口，建议您上传积极、美观、健康的内容，多展示您的特长、才艺等，这样才能收获更多老铁的喜爱。
