# 内容与发布 · 执行计划

本文是「业务模块设计 / 内容与发布」的实现执行文档。整体方案与数据结构分别见 [内容与发布](内容与发布.md) 和 [内容与发布-数据结构](内容与发布-数据结构.md)。

按依赖关系拆分为独立块，每块完成并通过验证后再进入下一块。

## 一、分块概览

| 序号 | 块 | 内容 | 依赖 |
| --- | --- | --- | --- |
| 1 | 数据层 | video 表与存储代码，状态与查询 | 无 |
| 2 | 存储接口 | 媒体存储抽象与本地磁盘实现 | 无 |
| 3 | 上传接口 | POST /api/uploads，格式校验与 faststart | 块2 |
| 4 | 创建视频 | POST /api/videos，事务创建与校验 | 块1、块3 |
| 5 | 详情与列表 | 详情、公开列表、我的作品 | 块1、块4 |
| 6 | 删除与状态 | DELETE 与状态流转 | 块1、块5 |

## 二、块1 数据层

目标：提供视频存储与查询代码。

内容：

- 按数据结构文档创建 video、video_stat 表，含约束与索引。
- 参数化查询：创建视频、按 ID 查询、按作者与状态分页列表。
- 事务内创建 video 与 video_stat。

验证：表结构与约束符合设计；存储代码有单元测试覆盖正常与异常路径。

完成定义：数据层代码与测试可用。

## 三、块2 存储接口

目标：定义媒体存储接口，提供本地磁盘实现。

内容：

- 定义 Storage 接口：保存文件、清理文件、返回 URL。
- 本地磁盘实现，目录与大小限制走配置。

验证：单元测试覆盖保存、返回 URL、清理失败文件。

完成定义：上传接口可直接调用存储接口。

## 四、块3 上传接口

目标：实现 POST /api/uploads。

内容：

- 鉴权与输入校验，文件大小与扩展名检查。
- 校验 MIME、时长、分辨率和编码，MP4/MOV faststart。
- 写入存储，失败清理文件。
- 响应：200 媒体地址；400 格式非法；401 未登录；503 存储故障。

验证：覆盖成功、非法格式、超大文件、未登录与存储故障。

完成定义：上传接口独立可用。

## 五、块4 创建视频

目标：实现 POST /api/videos。

内容：

- 鉴权与输入校验，标题、简介长度。
- 校验媒体地址存在与格式。
- 事务创建 video（待审核）与 video_stat。
- 响应：201 视频详情；400 输入错误；401 未登录；409 幂等冲突。

验证：覆盖成功、输入错误、鉴权和幂等。

完成定义：创建视频闭环可用。

## 六、块5 详情与列表

目标：实现详情、公开列表和我的作品。

内容：

- GET /api/videos/{videoId}：公开可见视频返回详情和计数，否则 404。
- GET /api/users/{userId}/videos：只返回已发布。
- GET /api/users/me/videos：返回自己的有效视频。

验证：覆盖已发布、未发布、不存在与权限路径。

完成定义：浏览能力可用。

## 七、块6 删除与状态流转

目标：实现删除与状态变更。

内容：

- DELETE /api/videos/{videoId}：作者或管理软删除。
- 验证下架、驳回状态流转与返回值。

验证：作者删除成功、非作者权限错误、状态一致。

完成定义：内容发布生命周期闭环可用。

## 八、推进说明

每块完成后更新本文状态，并在「服务可用性与高并发治理.md」业务模块行同步进度。
