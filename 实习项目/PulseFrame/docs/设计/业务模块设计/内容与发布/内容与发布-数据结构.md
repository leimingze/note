# MySQL 表

流程说明见 [内容与发布](内容与发布.md)。本文件定义视频发布所需的数据结构。

1. 通用约定
```text
使用 MySQL 8.0.16 及以上版本、InnoDB，外键与 CHECK 约束必须生效。
video.author_id 引用 users.id，使用服务端生成的规范小写 UUIDv4。
视频 ID 自增 BIGINT，作为视频主体引用。
所有 DATETIME(3) 均由应用按 UTC 写入。
下表未注明“可空”的字段均为 NOT NULL；created_at、updated_at 由应用维护。
```

1.1 video：视频主体表

| 字段 | 类型 | 默认值或约束 | 用途 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | 主键，自增 | 视频 ID |
| author_id | CHAR(36) | users.id 的外键 | 作者 ID |
| title | VARCHAR(128) | 无默认值 | 视频标题 |
| description | VARCHAR(1000) | 可空 | 视频简介 |
| media_url | VARCHAR(512) | 无默认值 | 视频媒体地址 |
| cover_url | VARCHAR(512) | 可空 | 封面地址 |
| status | TINYINT UNSIGNED | 默认1，CHECK 限定1-4 | 1待审核/2已发布/3下架/4删除 |
| reject_reason | VARCHAR(200) | 可空 | 审核驳回原因 |
| published_at | DATETIME(3) | 可空 | 审核通过发布时间 |
| created_at | DATETIME(3) | 创建时 UTC 时间 | 创建时间 |
| updated_at | DATETIME(3) | 最近修改时 UTC 时间 | 修改时间 |

```text
索引：
- idx_video_author_status (author_id, status, created_at)：作者作品列表
- idx_video_status_published (status, published_at, id)：Feed 与公开列表
```

1.2 video_stat：视频计数表

| 字段 | 类型 | 默认值或约束 | 用途 |
| --- | --- | --- | --- |
| video_id | BIGINT UNSIGNED | 主键，同时为 video.id 外键 | 视频 ID |
| like_count | INT UNSIGNED | 默认0 | 点赞数 |
| comment_count | INT UNSIGNED | 默认0 | 评论数 |
| favorite_count | INT UNSIGNED | 默认0 | 收藏数 |
| view_count | INT UNSIGNED | 默认0 | 播放数 |
| created_at | DATETIME(3) | 创建时 UTC 时间 | 创建时间 |
| updated_at | DATETIME(3) | 最近修改时 UTC 时间 | 修改时间 |

```text
发布视频时在同一事务创建 video 与 video_stat。
计数由互动模块维护，本模块读取展示。
```

# Redis key-value

当前内容与发布模块不使用 Redis 持久化计数。高频计数读写与一致性方案在互动模块中评估，本模块仅保存 MySQL 计数基线。
