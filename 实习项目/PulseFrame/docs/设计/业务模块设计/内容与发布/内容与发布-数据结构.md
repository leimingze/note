# MySQL 表

流程说明见 [内容与发布](内容与发布.md)。本文件只保留完成发布闭环必需的字段，其余观察字段按需再加。

通用约定：使用 MySQL 8.0.16 及以上、InnoDB，外键与 CHECK 约束生效；author_id 引用 users.id（规范小写 UUIDv4）；视频 ID 自增 BIGINT；DATETIME(3) 由应用按 UTC 写入；未注明"可空"的字段均为 NOT NULL。

## 1. video：视频主体表（12 字段）

| 字段 | 类型 | 约束 | 用途 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | 主键，自增 | 视频 ID |
| author_id | CHAR(36) | users.id 外键 | 作者 ID |
| title | VARCHAR(64) | 默认 '我发布了新视频，快来看看!' | 视频标题，未提供时使用默认文案 |
| media_url | VARCHAR(512) | 无默认 | 视频地址 |
| cover_url | VARCHAR(512) | 可空 | 封面地址 |
| status | TINYINT UNSIGNED | 默认1，CHECK 限定1-3 | 1待审核/2已发布/3已驳回 |
| reject_reason | VARCHAR(200) | 可空 | 驳回原因 |
| submitted_at | DATETIME(3) | 可空 | 提交审核时间；为空表示草稿且未提交 |
| updated_at | DATETIME(3) | 最近编辑时间 | 草稿列表排序依据 |
| hidden_at | DATETIME(3) | 可空 | 作者隐藏时间；非空表示仅自己可见 |
| deleted_at | DATETIME(3) | 可空 | 回收站删除时间；保留 7 天，逾期由清理任务彻底删除 |
| created_at | DATETIME(3) | 创建时间 | 创建时间，兼作发布排序基准 |

```text
索引：
- idx_video_author_status (author_id, status, created_at)：作者作品列表
- idx_video_author_draft (author_id, submitted_at, created_at)：草稿列表
- idx_video_status (status, created_at, id)：Feed 与公开列表
- idx_video_deleted (deleted_at)：回收站超期扫描
```

说明：status 只表示发布流程，草稿通过 submitted_at 为空体现，隐藏由 hidden_at 表达，删除与下架由 deleted_at 承担并保留 7 天；description、published_at 非必需，用到时再加。

### 草稿、待审核与已驳回的关系

三者表达不同信息，不并列等同：

- 草稿：submitted_at 为空，作者尚未提交，不在审核链路，不对外可见，可继续编辑。
- 待审核：submitted_at 非空且 status=1，已提交等待审核平台裁决，不对外可见，作者不能再改发布字段。
- 已驳回：status=3，审核平台已驳回，不对外可见，作者可见驳回原因，可修改后重新提交。
- 隐藏：hidden_at 非空，仅作者自身可见，可随时恢复公开，不影响 status 与审核结果。
- 回收站：deleted_at 非空，仅作者可通过恢复接口在 7 天内恢复，逾期由清理任务彻底删除。

判断维度：submitted_at 区分是否已提交，status 表示提交后的流转结果，hidden_at 表示作者对外的可见性，deleted_at 表示回收站保留期。草稿不是状态枚举里的冗余值。

## 2. video_stat：视频计数表（5 字段）

| 字段 | 类型 | 约束 | 用途 |
| --- | --- | --- | --- |
| video_id | BIGINT UNSIGNED | 主键，video.id 外键 | 视频 ID |
| like_count | INT UNSIGNED | 默认0 | 点赞数 |
| comment_count | INT UNSIGNED | 默认0 | 评论数 |
| favorite_count | INT UNSIGNED | 默认0 | 收藏数 |
| view_count | INT UNSIGNED | 默认0 | 播放数 |

```text
发布视频时在同一事务创建 video 与 video_stat；计数由互动模块维护，本模块读取展示。
```

## 3. review_task：送审记录表（6 字段）

| 字段 | 类型 | 约束 | 用途 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | 主键，自增 | 任务 ID |
| video_id | BIGINT UNSIGNED | video.id 外键 | 关联视频 |
| status | TINYINT UNSIGNED | 默认1，CHECK 限定1-3 | 1待审/2通过/3驳回 |
| reason | VARCHAR(200) | 可空 | 驳回原因 |
| review_source | VARCHAR(64) | 可空 | 审核平台或回调来源标识 |
| created_at | DATETIME(3) | 创建时间 | 送审记录创建时间 |

```text
索引：idx_task_video (video_id)、idx_task_status (status, created_at)。
创建视频时同一事务生成送审记录；审核平台回调写入 status 与 reason，重复回调幂等。
```

## 精简取舍说明

相比早期草案，删去了 description、published_at、final_decision、target_type、operator_type，以及 review_decision_log 表；status 收敛为三种，草稿与逻辑删除分别由 submitted_at、deleted_at 表达。title、media_url、cover_url 与 status 是发布闭环必需；reject_reason 支撑驳回展示；created_at 兼作排序；计数四值留给互动模块。后续若需 Agent 决策追溯，再加决策日志表即可，不影响现有结构。
