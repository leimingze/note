# MySQL 表

流程说明见 [内容与发布](内容与发布.md)。本文件只保留完成发布闭环必需的字段，其余观察字段按需再加。

通用约定：使用 MySQL 8.0.16 及以上、InnoDB，外键与 CHECK 约束生效；author_id 引用 users.id（规范小写 UUIDv4）；视频 ID 自增 BIGINT；DATETIME(3) 由应用按 UTC 写入；未注明"可空"的字段均为 NOT NULL。

## 1. video：视频主体表（8 字段）

| 字段 | 类型 | 约束 | 用途 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | 主键，自增 | 视频 ID |
| author_id | CHAR(36) | users.id 外键 | 作者 ID |
| title | VARCHAR(64) | 无默认 | 视频标题 |
| media_url | VARCHAR(512) | 无默认 | 视频地址 |
| cover_url | VARCHAR(512) | 可空 | 封面地址 |
| status | TINYINT UNSIGNED | 默认1，CHECK 限定1-5 | 1待审核/2已发布/3已驳回/4已下架/5已删除 |
| reject_reason | VARCHAR(200) | 可空 | 驳回原因 |
| created_at | DATETIME(3) | 创建时间 | 创建时间，兼作发布排序基准 |

```text
索引：
- idx_video_author_status (author_id, status, created_at)：作者作品列表
- idx_video_status (status, created_at, id)：Feed 与公开列表
```

说明：状态五种对应完整生命周期，删除采用软删除；description、published_at、updated_at 非必需，用到时再加。

## 2. video_stat：视频计数表（5 字段）

| 字段 | 类型 | 约束 | 用途 |
| --- | --- | --- | --- |
| video_id | BIGINT UNSIGNED | 主键，video.id 外键 | 视频 ID |
| like_count | INT UNSIGNED | 默认0 | 点赞数 |
| comment_count | INT UNSIGNED | 默认0 | 评论数 |
| favorite_count | INT UNSIGNED | 默认0 | 收藏数 |
| view_count | INT UNSIGNED | 默认0 | 播放数 |

```text
发布视频时在同一事务创建 video 与 video_stat；计数由互动模块维护，本模块读取展示。
```

## 3. review_task：审核任务表（6 字段）

| 字段 | 类型 | 约束 | 用途 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | 主键，自增 | 任务 ID |
| video_id | BIGINT UNSIGNED | video.id 外键 | 关联视频 |
| status | TINYINT UNSIGNED | 默认1，CHECK 限定1-3 | 1待审/2通过/3驳回 |
| reason | VARCHAR(200) | 可空 | 驳回原因 |
| updated_by | CHAR(36) | 可空，users.id 外键 | 审核人 |
| created_at | DATETIME(3) | 创建时间 | 任务创建时间 |

```text
索引：idx_task_video (video_id)、idx_task_status (status, created_at)。
创建视频时同一事务生成待审任务；人工审核直接记录在 status 与 reason，不再单列决策日志。
```

## 精简取舍说明

相比早期草案，删去了 description、published_at、updated_at、final_decision、target_type、operator_type，以及 review_decision_log 表。title、media_url、cover_url 与 status 是发布闭环必需；reject_reason 支撑驳回展示；created_at 兼作排序；计数四值留给互动模块。后续若需 Agent 决策追溯，再加决策日志表即可，不影响现有结构。

# Redis key-value

当前内容与发布模块不使用 Redis 持久化计数，仅保存 MySQL 计数基线；高频计数处理在互动模块中评估。
