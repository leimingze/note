# 内容与发布

短视频内容创建、上传与发布的业务闭环。

## 背景

PulseFrame 定位为 Go 短视频社交平台。平台需要用户发布视频，并让审核通过的视频进入 Feed 与其他用户浏览。没有发布能力，后续的 Feed、播放、互动和推荐都缺少数据来源。

本项目参考 GCFeed 的单向内容业务，其中视频模块覆盖发布、详情、列表、上传和逻辑删除；直播参考项目不具备短视频发布能力，不作为本模块参考。GCFeed 仅作为业务范围与工程思路参考，不直接作为本项目的代码基础，需求、数据模型和接口将从零推导。

## 需求

### 核心功能

- 用户能够上传视频文件，系统校验文件格式并生成可访问的媒体与封面地址。
- 用户能够填写标题、简介并选择封面，先将视频保存为草稿（未提交），之后补全并提交审核。
- 用户能够查询视频详情、自己的作品列表和公开作品列表。
- 系统支持发布、驳回、删除和详情等状态流转，状态由审核决策驱动。
- 视频创建后进入待审核，业务端把待审内容送往独立审核平台，并接收平台返回的通过与驳回结论，作者可查看驳回原因。
- 作者可以删除自己的视频，删除后不再对外可见。
- 作者可以隐藏或恢复公开自己的作品，隐藏期间仅自己可见。

### 非功能指标

- 创建、列表和详情接口的正确性、并发与一致性、失败恢复。
- 敏感信息保护、输入校验、权限控制。
- 视频对象不可变：媒体地址、封面地址存储后不修改。

### 数据规模与边界

- 视频元数据按平台规模线性增长，单条记录小，使用关系型数据库存储。
- 媒体文件存储上限在配置中定义，超出时直接拒绝。
- 本模块不处理视频创作、剪辑、滤镜和特效。
- 审核在独立平台进行；本模块只保存送审记录与回写结果，后续内容安全 Agent 等工作流接入时复用同一套待审实体。

### 暂不处理

- 上传进度与断点续传：短视频单次上传体量小，实现单请求整传，客户端使用 XMLHttpRequest upload.onprogress 上报进度，不做服务端轮询、分片与断点续传；失败直接整文件重传。
- 分布式对象存储集群管理。
- 转码预热，仅保留快速启动校验。

## 方案选型

### 视频标识

视频 ID 使用 64 位自增主键。视频创建频率低、生命周期内引用频繁，自增主键便于索引与游标分页；对外接口暴露视频 ID，不承担鉴权职责。

### 媒体存储

媒体文件（视频、封面）使用存储接口抽象，对外返回稳定 URL，对象写入存储系统。计划接入在线对象存储服务（S3 兼容，连接方式待提供），接口抽象用于接入时替换实现而不改动业务代码。接入前先用本地磁盘实现支撑开发和联调。

上传走服务端接收：客户端先调用上传接口取得媒体地址，再创建视频。这样媒体校验、文件清理和错误反馈集中在上传接口，创建视频时不重复处理文件。

### 视频状态

status 使用 TINYINT 枚举，仅表示发布流程：1 待审核、2 已发布、3 已驳回。是否已提交由 submitted_at 区分：为空表示草稿，不为空表示进入审核链路。删除与下架统一由 deleted_at 承担，不占用 status 枚举。Feed 只读取已发布且未删除的视频。

审核由独立平台负责：提交审核后，业务端将待审内容送往审核平台；平台通过回调返回决定，业务端据此更新 status 与驳回原因。开发阶段使用本地模拟桩自动通过或驳回，保证流程在真正接入审核平台前可验证。

作者可见性由 hidden_at 独立表达：非空表示作者隐藏，仅自己可见，可随时恢复；该字段不影响 status 与审核结果，也不占枚举。

### 播放优化

上传媒体格式校验：扩展名、MIME、大小、时长、分辨率和编码。MP4/MOV 上传后执行 faststart，将播放元数据前置，便于拖动进度与快速起播。

## 核心流程

### 上传媒体

```text
1. 客户端携带 JWT 调用 POST /api/uploads 上传文件
2. 服务端校验扩展名、MIME、大小、时长、分辨率和编码
3. 不符合要求时拒绝，清理已写入文件
4. 写入存储接口，返回媒体地址
5. MP4/MOV 执行 faststart 优化
```

### 创建视频

```text
1. 客户端携带 JWT 调用 POST /api/videos，创建草稿，标题可选
2. 草稿阶段可调用 PATCH /api/videos/{videoId} 补全标题、简介与媒体地址
3. 调用 POST /api/videos/{videoId}/submit 提交审核，校验完整性后写入 submitted_at、status=待审核，并生成送审记录
4. 返回视频详情
```

### 状态流转

```text
- 创建：草稿（submitted_at 为空，不对外可见）
- 提交审核：待审核
- 审核平台通过：已发布
- 审核平台驳回：审核未通过
- 删除/下架：逻辑删除（deleted_at 有值，仅作者或外部安全策略）
```

## 接口设计

| 方法 | 路径 | 作用 | 鉴权 | 幂等键 |
| --- | --- | --- | --- | --- |
| POST | /api/uploads | 上传媒体文件 | JWT | 支持 |
| POST | /api/videos | 创建草稿 | JWT | 支持 |
| PATCH | /api/videos/{videoId} | 更新草稿 | JWT(作者) | 支持 |
| POST | /api/videos/{videoId}/submit | 提交审核 | JWT(作者) | 支持 |
| PUT | /api/videos/{videoId}/visibility | 隐藏或恢复公开作品 | JWT(作者) | 支持 |
| GET | /api/videos/{videoId} | 查询视频详情 | 公开 | 无 |
| POST | /api/review/webhook | 审核平台回调审核结果 | 签名校验 | 支持 |
| DELETE | /api/videos/{videoId} | 删除自己的视频 | JWT(作者) | 支持 |
| GET | /api/users/{userId}/videos | 查询公开作品列表 | 公开 | 无 |
| GET | /api/users/me/videos | 查询我的作品列表 | JWT | 无 |

## 非功能设计

- 上传接口限制文件大小和格式，防止大文件耗尽资源。
- 提交审核时在事务内创建 video_stat 与送审记录，失败回滚。
- 草稿未提交时不生成送审记录；提交后禁止再编辑发布字段。
- 回调校验来源签名，只允许审核平台写入结果，重复回调幂等，驳回原因写入 reject_reason。
- 删除校验作者身份，仅本人可删，其他账号返回权限错误。
- 隐藏仅影响他人可见性，我的作品列表仍返回隐藏记录，恢复公开不改变审核结果。
- 公开列表只返回已发布视频；我的作品可返回自己的有效视频。
