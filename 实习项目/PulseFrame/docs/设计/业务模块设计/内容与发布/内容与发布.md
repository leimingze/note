# 内容与发布

短视频内容创建、上传与发布的业务闭环。

## 背景

PulseFrame 定位为 Go 短视频社交平台。平台需要用户发布视频，并让审核通过的视频进入 Feed 与其他用户浏览。没有发布能力，后续的 Feed、播放、互动和推荐都缺少数据来源。

本项目参考 GCFeed 的单向内容业务，其中视频模块覆盖发布、详情、列表、上传和软删除；直播参考项目不具备短视频发布能力，不作为本模块参考。GCFeed 仅作为业务范围与工程思路参考，不直接作为本项目的代码基础，需求、数据模型和接口将从零推导。

## 需求

### 核心功能

- 用户能够上传视频文件，系统校验文件格式并生成可访问的媒体与封面地址。
- 用户能够填写标题、简介，并选择封面后创建视频，创建后进入待审核状态。
- 用户能够查询视频详情、自己的作品列表和公开作品列表。
- 系统支持发布、驳回、删除和详情等状态流转，状态与审核模块联动。
- 作者或管理人员能够删除视频，删除后不再对外可见。

### 非功能指标

- 创建、列表和详情接口的正确性、并发与一致性、失败恢复。
- 敏感信息保护、输入校验、权限控制。
- 视频对象不可变：媒体地址、封面地址存储后不修改。

### 数据规模与边界

- 视频元数据按平台规模线性增长，单条记录小，使用关系型数据库存储。
- 媒体文件存储上限在配置中定义，超出时直接拒绝。
- 本模块不处理视频创作、剪辑、滤镜和特效。
- 审核任务处理由审核模块负责，本模块只提供视频状态数据和状态查询。

### 暂不处理

- 上传进度与断点续传：短视频单次上传体量小，实现单请求整传，客户端使用 XMLHttpRequest upload.onprogress 上报进度，不做服务端轮询、分片与断点续传；失败直接整文件重传。
- 分布式对象存储集群管理。
- 转码预热，仅保留快速启动校验。

## 方案选型

### 视频标识

视频 ID 使用 64 位自增主键。视频创建频率低、生命周期内引用频繁，自增主键便于索引与游标分页；对外接口暴露视频 ID，不承担鉴权职责。

### 媒体存储

媒体文件（视频、封面）使用存储接口抽象，当前实现为本地磁盘存储，目录可通过配置指定。存储接口返回稳定的 URL，对象存入数据库。后续需要迁移对象存储时，替换存储实现并保持接口不变。

上传走服务端接收：客户端先调用上传接口取得媒体地址，再创建视频。这样媒体校验、文件清理和错误反馈集中在上传接口，创建视频时不重复处理文件。

### 视频状态

状态使用 TINYINT 枚举，可扩展。创建即进入待审核，公开可见需审核通过。Feed 只读取已发布视频。删除采用软删除，保留记录以避免计数与关联失效。

### 播放优化

上传媒体格式校验：扩展名、MIME、大小、时长、分辨率和编码。MP4/MOV 上传后执行 faststart，将播放元数据前置，便于拖动进度与快速起播。

## 核心流程

### 上传媒体

```text
1. 客户端携带 JWT 调用 POST /api/uploads 上传文件
2. 服务端校验扩展名、MIME、大小、时长、分辨率和编码
3. 不符合要求时拒绝，清理已写入文件
4. 写入存储接口，返回媒体地址
5. MP4/MOV 执行 faststart 优化
```

### 创建视频

```text
1. 客户端携带 JWT 调用 POST /api/videos，提交标题、简介和媒体地址
2. 校验输入长度与媒体地址
3. 创建 video 记录，状态为待审核，写入 video_stat 初始行
4. 返回视频详情
```

### 状态流转

```text
- 创建：待审核
- 审核通过：已发布
- 审核驳回：审核未通过
- 下架：已下架（管理人员操作）
- 删除：软删除（作者或管理人员操作）
```

## 接口设计

| 方法 | 路径 | 作用 | 鉴权 | 幂等键 |
| --- | --- | --- | --- | --- |
| POST | /api/uploads | 上传媒体文件 | JWT | 支持 |
| POST | /api/videos | 创建并提交视频 | JWT | 支持 |
| GET | /api/videos/{videoId} | 查询视频详情 | 公开 | 无 |
| DELETE | /api/videos/{videoId} | 删除视频 | JWT(作者/管理) | 支持 |
| GET | /api/users/{userId}/videos | 查询公开作品列表 | 公开 | 无 |
| GET | /api/users/me/videos | 查询我的作品列表 | JWT | 无 |

## 非功能设计

- 上传接口限制文件大小和格式，防止大文件耗尽资源。
- 创建视频使用事务写入 video 与 video_stat，失败回滚。
- 删除校验作者身份，非作者返回权限错误。
- 公开列表只返回已发布视频；我的作品可返回自己的有效视频。
