# 从模块代码生成交互流程画布（通用提示词）

下面是可直接复用的提示词，用于把任意代码模块的结构与逻辑生成为交互式 HTML 画布。替换「模块范围」和「相关文件」即可适配不同模块。

````text
请阅读以下模块代码，生成一份用于复盘的可交互 HTML 画布。

## 模块范围
（在这里填写模块职责与涉及的主流程，例如：模块如何初始化、运行、执行核心逻辑并释放资源）

## 相关文件
（在这里列出相关文件相对路径，每行一个）

## 输出形式
交付单个自包含 HTML 文件，双击即可在浏览器打开，不依赖外部网络或构建工具。

## 内容要求
1. 以方法为基本卡片，完整覆盖模块内关键流程：入口、配置、初始化、核心逻辑、退出/清理。
2. 卡片内部按方法执行顺序竖排步骤，每步用自然语言说明它在做什么，而不是只抄代码标识。
3. 被调用但未单独展开的方法，在调用它的步骤里用一句话说明其职责与角色。
4. 保留关键失败分支（如校验失败、初始化失败、清理失败），在节点描述中注明错误去向。
5. 涉及配置参数时（环境变量、默认值、含义、校验规则），在卡片中一并呈现。
6. 只包含本模块职责相关部分，不混入无关模块。
7. 若需要“面试/讲解卡片”（独立长文本卡片，不与任何卡片连线），将内容组织为：一句总述 + 若干常见问题条目，每条写成“问题是什么 → 怎么解决 → 在代码里由什么承载”的完整叙述，便于后续口述。

## 结构与布局要求
8. 卡片之间用连线表示调用关系，支持多对多：一个方法调用几个方法，就引出几条线。
9. 被调用卡片放在调用方右侧；同一调用方引出的多个子卡片按步骤顺序自上而下排列，尽量减少连线交叉。
10. 每张卡片：
    - 头部显示方法名与其文件地址（项目内相对路径；标准库/外部库调用注明来源）。
    - 左边缘放置入口端口，右边缘按步骤放置出口端口，出口端口与该步骤行垂直对齐。
11. 面试/讲解卡片为独立长文本卡片：宽度大于功能卡，内部直接展示正文，不生成步骤与端口，默认固定在主线第一个方法卡片的正下方，稍留间距。
12. 所有卡片在全生命周期内必须互不覆盖，包括普通方法卡片、步骤较多的长卡片和面试/讲解卡片。不得用遮挡、隐藏、缩小文字或依赖层级关系处理重叠。
13. 初始布局必须读取卡片渲染后的实际宽度和高度进行碰撞检测，不能只用固定卡片高度估算。卡片之间保留一致的横向和纵向间距。
14. 发现重合时，优先将后处理的卡片向下移动；同一区域仍然冲突时再向右移动。移动后必须重新检查附近全部卡片，直到没有任何两张卡片相交。
15. 自动布局完成后，画布宽度和高度必须扩展到所有卡片的外边界之外，并保留底部和右侧留白。卡片不得超出画布或被画布裁切。
16. 初次渲染、字体加载完成、主题切换和自动布局结束后，都要重新计算端口位置与连线路径。自动调整布局不能造成端口错位或连线连接到错误步骤。

## 交互要求
17. 卡片可拖拽移动，连线自动跟随。拖动过程中也必须执行碰撞检测：可能与其他卡片重合时限制移动或自动避让，松开鼠标后不得留下卡片重合。
18. 空白处按住拖动可平移画布。
19. 顶部工具栏提供锁定按钮：一键固定当前全部卡片，再次点击解锁；锁定期间卡片不可拖动，画布平移保持可用。
20. 顶部工具栏显示图例。
21. 顶部工具栏提供白天/夜间主题切换按钮，点击在两种配色间切换，并记住上次选择。

## 配色与视觉
22. 按功能分组着色，各功能使用固定色系；分组标签可用“入口/编排、配置/校验、装配/初始化、核心逻辑/驱动、服务/运行”等，按模块实际情况调整。
23. 卡片白底、圆角、细边框；入口端口用红色边框，出口端口用绿色边框；连线使用灰色曲线。
24. 背景使用点阵网格；顶部工具栏白底、底部细边框。
25. 使用中文界面与说明，字体使用系统默认中文字体组合。

## 交付检查
26. 交付前用浏览器实际渲染检查全部卡片，确认不存在任意两张卡片相交。
27. 检查最长卡片、面试/讲解卡片、相邻列卡片和画布底部卡片，确认没有被覆盖、裁切或超出画布。
28. 检查自动布局和拖拽后的连线路径、端口对齐、锁定和平移功能。任一项检查未通过时，修正后重新检查再交付。
````
