# 接口契约

本文档定义订单服务对外接口的请求、响应、错误码与幂等约定，是编写用例和自动化的依据。

## 通用约定

- Base URL：`http://127.0.0.1:30051`
- 数据格式：`application/json`
- 鉴权：请求头 `X-User-Id` 携带用户标识，缺失时返回 401
- 幂等：请求头 `X-Idempotency-Key` 携带幂等键，同一订单同一幂等键的重复请求只执行一次

## 接口列表

### 查询订单详情

`GET /api/orders/{order_id}`

| 项目 | 内容 |
| --- | --- |
| 请求头 | X-User-Id 必填 |
| 成功响应 200 | `{"id": 1, "order_no": "2026082300000001", "user_id": "10001", "status": "PENDING_PAYMENT", "amount": "249.00", "subject": "小米手环9 NFC版 智能手环 黑色标准版", "created_at": "...", "cancelled_at": null}` |
| 失败响应 | 401 未登录；404 订单不存在或不属于当前用户 |

行为说明：

- 首次读取走数据库并写入 Redis 缓存，缓存 TTL 为 5 秒。
- 缓存命中时同样校验归属，避免越权读到他人缓存。
- 取消成功后缓存键被删除，下一次读取立即回到数据库新状态。

### 取消订单

`POST /api/orders/{order_id}/cancel`

| 项目 | 内容 |
| --- | --- |
| 请求头 | X-User-Id 必填；X-Idempotency-Key 可选；X-Fault-Injection 可选（测试用） |
| 成功响应 200 | `{"order_id": 1, "status": "CANCELLED", "success": true, "message": "取消成功"}` |
| 已取消响应 200 | `success` 为 false，message 为“订单已取消，无需重复操作” |
| 失败响应 | 401 未登录；404 越权或不存在；409 状态不允许取消；500 数据库故障注入 |

行为说明：

- 只有待支付、待发货订单可以取消，取消后状态变为 `CANCELLED`。
- 订单状态更新与待发送事件写入在同一个 MySQL 事务中提交。
- 提交成功后当前请求删除 Redis 缓存；后台任务独立把待发送事件发送到 RabbitMQ。
- 已发货、已完成订单返回 409，订单状态与事件均不变化。

## 错误码

| HTTP 状态码 | code | 含义 |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 缺少 X-User-Id |
| 404 | ORDER_NOT_FOUND | 订单不存在或不属于当前用户 |
| 409 | ORDER_NOT_CANCELLABLE | 当前状态不允许取消 |
| 500 | DB_FAULT_SIMULATED | 数据库故障注入，事务已回滚 |

错误响应体由 FastAPI 统一包装为 `{"detail": {"code": "...", "message": "..."}}`。

## 故障注入开关（测试专用）

| 开关 | 方式 | 效果 |
| --- | --- | --- |
| 数据库失败 | 取消请求携带 `X-Fault-Injection: db` | 在事务提交前抛错并回滚，接口返回 500，订单与事件均不变化 |
| MQ 发送失败 | `redis-cli -p 30054 set fault:mq_publish 1` | 后台任务暂停发送，事件保持 PENDING；删除该键后恢复发送 |

故障注入开关只用于学习与测试，生产环境不应暴露。
