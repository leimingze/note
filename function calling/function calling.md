# Function Calling（函数调用）
## 本质
让大模型根据用户指令，判断是否需要调用预定义的外部函数，并生成结构化的函数名和参数；本地 Harness 负责真正执行函数，再将执行结果返回给大模型，由大模型生成最终的自然语言回答。

## 如何工作
```text
用户自然语言
  → 大模型判断是否调用工具
  → 大模型生成函数名和参数
  → Harness 执行函数
  → 函数返回结果
  → Harness 将结果返回给大模型
  → 大模型生成最终回答
```

# 怎么训练出来的？
1. 预训练
学自然语言、代码、知识和各种模式，本质是建立通用能力：用海量文本、代码做“下一个 token 预测”。
2. 监督微调（sft）
才专门教它工具调用：用户问天气 → 不直接瞎答 → 选择 get_weather → 填好参数。
3. 对齐
通过人类偏好数据、奖励模型、RLHF / DPO 等方式调整：哪种回答更好、更安全、更符合人类意图。

# 工具调用失败怎么解决
确定性错误交给程序处理，语义性错误交给模型处理。
1. 参数失败：用 JSON Schema / 参数校验先拦截，再把错误信息回传给模型，让它重新生成参数。
2. 工具执行失败：Harness 做重试、超时控制、异常捕获。
3. 逻辑调用失败：比如模型选错工具，或者工具结果不满足任务。把“工具返回结果 + 错误原因”重新交给模型，让它重新规划。
