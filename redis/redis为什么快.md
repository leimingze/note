# Redis 高性能原因汇总

| 层级 | 原因 | 详细说明 |
|---|---|---|
| ① 内存存储 | 数据在内存中 | 内存访问纳秒级（~100ns），磁盘毫秒级（~10ms），差 10 万倍 |
| ② 高效数据结构 | 专门优化的数据结构 | SDS、quicklist、skiplist 等，时间复杂度低 |
| ③ 单线程模型 | 避免上下文切换和锁竞争 | 6.0 之前命令执行是单线程，无需加锁，6.0之后命令执行仍然但线程，网络io可以多线程 |
| ④ IO 多路复用 | epoll 机制 | 单线程监听多个 socket，非阻塞 IO |
| ⑤ RESP 协议 | 简单高效 | 文本协议，解析快 |
