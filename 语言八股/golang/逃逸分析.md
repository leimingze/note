编译器在编译期做的一种分析：判断一个变量到底在栈上还算是堆上。
核心目标：尽量放在栈上，是在放不下再放到堆上。如果离开作用域后没被使用优先放栈上，否则放堆。
常见场景
```go
func newPerson(name string) *person {
    p := person{name: name}
    return &p
}//返回局部变量地址，p的地址被返回到函数外，调用者还能用，这就是逃逸了，编译器会把它分配到堆上。

func counter() func() int {
    i := 0
    return func() int {
        i++
        return i
    }
}//被闭包捕获

var g *int

func f() {
    x := 10
    g = &x
}//赋值给全局变量


```
