闭包=一个函数+它能访问到的外部变量
即使是外部函数已经执行完，闭包依然能记住并使用这些外部变量。
闭包的三个核心条件：
1. 必须有一个嵌套函数
2. 内部函数必须引用外部函数中的变量（非全局变量）
3. 外部函数必须返回这个内部函数

作用与好处：
1. 数据隐藏与封装：外部无法直接访问闭包记住的变量，只能通过调用闭包来操作
2. 避免使用全局变量：提供了一种在函数之间共享状态的优雅方式，减少了全局变量带来的污染和潜在风险。
3. 实现工厂函数。

场景一：
```go
func counter() func() int {
    count := 0
    return func() int {
        count++
        return count
    }
}
c := counter()
c() // 1
c() // 2
计数器等
```

场景2:回调函数
```go
func process(data string, callback func(string)) {
    // 处理完数据后调用回调
    callback(data)
}

msg := "hello"
process(msg, func(result string) {
    fmt.Println("处理结果：", result)
})
事件处理，异常同步

正常写法，不用闭包：数据流向是单向的：main → process，process 是终点
main 收集数据 → 全部塞给 process → process 里一把操作完。

闭包写法：数据流向变成了绕回来一圈：main → process → 回到 main
main 收集数据 → process 只负责流程 → 结果"回调"回 main → main 用自己的数据+结果一起操作

process的角度：只干自己的活，打印日志什么的不应该它管
```

场景3:函数工厂
```go
func multiplier(factor int) func(int) int {
    return func(x int) int {
        return x * factor
    }
}

double := multiplier(2)
triple := multiplier(3)

double(5) // 10
triple(5) // 15
```

场景4:defer+闭包（延迟执行）
```go
func example() {
    x := 10
    defer func() {
        fmt.Println("x =", x)
    }()
    x = 20
}
输出x=20
```
