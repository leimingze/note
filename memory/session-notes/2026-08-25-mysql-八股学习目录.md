## 验证时发现的坑（避免重复）

- 初始化脚本数字序列上限导致 users/products 少 1 条，已改为
  `WHERE n BETWEEN 0 AND seed-1`。
- 事务/隔离级别演示必须“同一连接内两次读”，用 `SELECT SLEEP` 保持事务，
  分两条 mysql 命令会开新连接导致 RR 演示失效。
- NotebookClient 需要传入 nb 对象而非路径；执行后要 `nbf.write` 才能把输出
  保存回 ipynb。
- `LIKE '20260825%'` 匹配全表会被优化器放弃索引，教学示例需用有选择性的前缀。
- `ORDER BY created_at DESC` 在 MySQL 8 走反向索引扫描不产生 filesort，
  演示 filesort 要用无索引排序列。
- binlog 文件名随 FLUSH LOGS 轮转，练习文件提示按 `SHOW MASTER STATUS`
  实际文件名执行。
