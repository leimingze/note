# ADR-0002：Agent Judge 超长 Prompt 不裁剪

日期：2026-08-24
状态：已采纳

## 背景

固定 `Qwen/Qwen3-4B-Instruct-2507` 提交运行原生 chat template 审计后，5,383 条 Prompt 中有 7 条超过 262,144 Token 原生上下文，其中最大长度为 1,747,763 Token。

## 决策

不对固定公开评测样本执行静默截断，也不从保真数据层删除超长记录；超窗样本按模型标记为上下文不可评测，保存独立清单，并在所有结果中报告覆盖数和覆盖率。

比较多个模型时，主结果使用各模型都能覆盖的公共样本集，补充结果分别报告各模型完整可覆盖集合；任何显式裁剪只能作为单独实验，并固定规则和受影响样本。

## 影响

Qwen3-4B 当前可直接评测 5,376/5,383 条 Prompt，覆盖率为 99.87%；7 条超窗记录不会获得伪造或经过隐式裁剪的模型预测。

## 替代方案

未采用尾部截断、按字符裁剪或摘要压缩，因为这些做法可能删除首错、工具返回或最终结果证据，并改变公开 Benchmark 的输入语义。

## 证据

- `agent测评/论文/实验/reports/token_audit.json`
- `agent测评/论文/实验/reports/token_audit.md`
- `agent测评/论文/实验/data/token_audit/qwen3_4b_instruct_2507_overflow.jsonl`

## 后续约束

零样本和训练评测脚本必须在推理前检查上下文长度；发现超窗时显式记录不可评测状态，不得自动截断、跳过后仍按全量样本计算指标，或用默认标签代替预测。
