# 简单介绍提示词工程
- 任务
- 上下文信息
- 参考示例
- 评估：根据结果，人工/返回给模型当前提示词是否有效，或者建立测试集。
- 迭代：落文档，方便迭代

# 写提示词技巧
- 构建多阶段流程：将多个提示词串联起来，每一步作为下一步的输出。
- 鼓励模型探索其他思路

# 如何提高任务稳定性与准确性
明确任务目标、输入含义、执行规则、边界条件和输出格式。
提供可靠的与任务相关的上下文。
复杂任务不建议让模型在一调用中同时完成理解、检索、决策和执行，而是拆成多个步骤。

# 如何压缩/裁剪prompt
1. 用简洁的语言描述事实、规则与要求
2. 如果特别长不能直接删除的历史信息，可以让大模型尝试总结一下。
