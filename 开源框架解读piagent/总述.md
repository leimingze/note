# packages 总述

以下顺序以理解 Pi 编程 Agent 的关键程度为依据，按阅读重要程度排列：模型调用和执行核心、编程应用及界面、工具扩展、状态与远程服务、运行观测与评估。目录树展示主要功能文件夹。

```text
packages/
├── ai/  # 1. 统一模型请求、响应和认证
├── agent/  # 2. Agent 执行核心，组织模型与工具循环
├── coding-agent/  # 3. 面向用户的编程 Agent 应用
├── tui/  # 4. 终端界面渲染和交互
├── mcp/  # 5. 连接外部 MCP 工具服务
├── codemode/  # 6. 执行组合调用工具的 JavaScript
├── chord/  # 7. 插件、服务及共享状态基础组件
├── durable/  # 8. 持久化会话和任务运行
├── protocol/  # 9. 远程会话通信格式
├── server/  # 10. 服务端连接和会话路由
├── client/  # 11. 客户端请求和服务订阅
├── env/  # 12. 远程文件及命令执行环境
├── telemetry/  # 13. 运行过程和用量相关观测
└── evals/  # 14. Agent 行为和文档效果评估
```

## 1. packages/ai 目录

`packages/ai` 是 Pi 框架中负责连接和调用 AI 模型的包，主要职责如下：

1. **统一请求格式**：上层使用统一的消息和调用参数，由该包转换成 OpenAI、Anthropic、Google 等厂商要求的请求格式。
2. **统一响应格式**：将各厂商返回的内容转换成统一的消息和流式事件，便于上层接收文本、推理内容和工具调用信息。
3. **管理模型目录**：提供各厂商的模型列表、能力和配置，支持模型查询及动态目录刷新。
4. **管理认证**：处理 API Key、OAuth 登录和凭据刷新，并将认证信息用于模型请求。
5. **支持不同模型能力**：处理工具声明和工具调用消息，支持图片输入、图片生成及结构化分类。
6. **统计用量和费用**：整理输入、输出和缓存的 Token 用量，并按模型价格计算费用。

```text
ai/                     # 统一模型调用、认证和响应处理的 AI 包
├── scripts/            # 模型目录生成、数据校验和测试资源生成脚本
├── src/                # 公共接口、模型管理及各功能的源码
│   ├── api/            # 各类模型 API 的请求发送、消息转换和响应解析
│   ├── auth/           # 凭据存储、认证解析和登录流程管理
│   │   └── oauth/      # 各服务商 OAuth 登录、授权回调和凭据刷新
│   ├── compat/         # 为扩展保留的旧版接口兼容类型
│   ├── providers/      # 各服务商的地址、认证、模型目录和调用配置
│   │   └── images/     # 为旧版接口注册内置图片生成 API
│   └── utils/          # 事件流、对话记录、参数校验、重试和错误诊断等公共工具
└── test/               # 模型调用、认证、工具、缓存和数据等功能的测试
    └── data/           # 测试使用的图片等输入资源
```


## 2. packages/agent（core）目录

`packages/agent` 对应 npm 包 `@earendil-works/pi-agent-core`，是 Pi 框架的 Agent 执行核心。它通过 `packages/ai` 提供的模型调用接口，组织对话、工具执行和后续调用，主要职责如下：

1. **组织 Agent 执行循环**：接收用户消息并调用模型；模型提出工具调用时，执行工具并将结果交给模型，继续生成回复。
2. **执行工具**：校验模型提供的工具参数，调用应用注册的工具，支持并行或顺序执行，并将执行结果或错误记录为工具结果消息。
3. **管理运行状态**：保存对话消息、当前模型、推理等级和可用工具，并维护流式回复、待执行工具及错误状态。
4. **提供运行事件**：发出 Agent、轮次、消息和工具执行的开始、更新及结束事件，供上层显示回复和执行进度。
5. **接收运行中的新消息**：通过 `steer()` 接收引导消息，在后续模型调用中调整任务；通过 `followUp()` 排队接收当前任务结束后的追加消息。
6. **控制运行过程**：提供发起对话、继续已有对话、取消当前运行、等待运行完成及重置状态等操作。
7. **提供扩展接口**：允许应用转换自定义消息、调整上下文、准备请求及决定轮次结束后的动作，也可以接入自定义模型调用函数或后端代理。

```text
agent/                      # Agent 执行循环、工具执行和状态管理的核心包
├── examples/               # 展示 Agent 与其他组件组合使用的示例
│   └── mcp-codemode/        # 展示连接 MCP 工具及通过 JavaScript 调用工具
├── src/                    # Agent、执行循环、公共类型和代理调用的源码
└── test/                   # Agent 状态、执行循环、代理及端到端调用的测试
    └── utils/              # 测试使用的工具实现和异步等待辅助函数
```

## 3. packages/coding-agent 目录

`packages/coding-agent` 是用户直接使用的 Pi 编程 Agent 应用，将模型调用、Agent 循环、工具和终端界面组合起来。

1. **提供使用入口**：支持终端交互、文本或 JSON 输出、RPC 控制和 TypeScript SDK 调用。
2. **提供编程工具**：内置文件读取、搜索、编辑、写入及命令执行工具，管理工具配置和结果展示。
3. **管理会话与上下文**：保存和恢复会话，支持会话分支、模型切换、上下文压缩、设置及项目指令加载。
4. **加载扩展资源**：支持扩展、skills、提示模板、主题和扩展包，并集成 MCP、codemode 及工具搜索。

```text
coding-agent/  # 面向用户的编程 Agent 应用
├── docs/  # 功能说明和使用文档
├── examples/  # 扩展、插件和 SDK 使用示例
├── install-lock/  # 独立安装所需的固定依赖信息
├── scripts/  # 开发、打包和辅助脚本
├── src/  # 应用入口和各功能源码
│   ├── bun/  # 独立 Bun 可执行程序的打包支持
│   ├── cli/  # 命令行参数和命令处理
│   ├── client/  # 应用服务的客户端接口
│   ├── core/  # 会话、工具、上下文压缩和扩展管理
│   ├── experimental/  # 持久化运行、插件及远程服务等实验功能
│   ├── extensions/  # MCP、codemode、工具搜索及 llama.cpp 内置扩展
│   ├── modes/  # 终端交互、文本输出和 RPC 运行模式
│   └── utils/  # 文件、命令、图片和终端等辅助功能
└── test/  # 功能、会话和协议的测试
```

## 4. packages/tui 目录

`packages/tui` 是终端界面组件库，为编程 Agent 等命令行应用提供交互与显示能力。

1. **渲染终端界面**：支持主屏幕和备用屏幕，以差异更新和同步输出显示内容，并处理滚动和浮层。
2. **提供界面组件**：包含编辑器、输入框、列表、Markdown、图片和布局组件，支持主题及自动补全。
3. **处理终端交互**：处理键盘、鼠标、粘贴、焦点和输入法，并提供不同系统的剪贴板等平台支持。

```text
tui/  # 终端界面渲染和交互组件库
├── native/  # 系统剪贴板等原生功能
│   ├── darwin/  # macOS 原生实现和预编译模块
│   ├── linux/  # Linux 原生实现和预编译模块
│   └── win32/  # Windows 原生实现和预编译模块
├── src/  # 渲染、输入、布局和终端控制源码
│   └── components/  # 编辑器、文本、列表和图片等组件
└── test/  # 界面渲染和输入行为测试
```

## 5. packages/mcp 目录

`packages/mcp` 是独立的 Model Context Protocol 客户端，供应用连接外部 MCP 工具服务。

1. **连接 MCP 服务**：支持 stdio 和 Streamable HTTP 传输，管理初始化、请求关联、超时、取消和进度通知。
2. **发现和调用工具**：读取服务提供的工具列表，发送工具调用，并将返回内容转换为模型可使用的文本和图片。
3. **处理服务认证**：支持 OAuth 服务发现、授权码与 PKCE 登录、凭据刷新及权限追加授权。

```text
mcp/  # MCP 服务连接和工具调用客户端
├── LICENSES/  # 包含改编代码的第三方许可证
├── src/  # 客户端和工具结果转换源码
│   ├── oauth/  # MCP OAuth 授权及凭据刷新
│   ├── protocol/  # MCP 消息类型和协议校验
│   ├── testing/  # 内存测试传输及测试辅助功能
│   └── transports/  # stdio 和 Streamable HTTP 传输实现
└── test/  # 协议、传输、工具和认证测试
```

## 6. packages/codemode 目录

`packages/codemode` 在 QuickJS WebAssembly 沙箱中执行模型生成的 JavaScript，使模型能通过程序组合调用应用提供的工具。

1. **执行工具调用脚本**：向脚本注入工具和输出函数，支持顺序或并发调用，只将选定输出和返回值交给上层。
2. **控制执行资源**：通过 worker 隔离执行，处理超时、取消和内存限制；脚本访问外部能力须经过注入的函数。
3. **组织脚本输入输出**：解析脚本选项，生成工具类型声明，记录调用结果，并通过存储读写结果交由应用保存跨次数据。

```text
codemode/  # 模型生成 JavaScript 的沙箱执行组件
├── src/  # 沙箱接口、脚本选项及工具声明源码
│   └── runtime/  # QuickJS worker、工具调用桥接及运行环境
└── test/  # 执行、取消、资源限制和结果处理测试
```

## 7. packages/chord 目录

`packages/chord` 是可独立使用的应用组合组件，为插件、服务和共享状态提供基础能力，供 Pi 多个包复用。

1. **组合插件和服务**：以 facet 组织插件在不同环境中的部分，校验服务依赖，管理加载、激活、替换和资源释放。
2. **同步共享状态**：记录 JSON 状态变化并发布快照及增量，使本地和远程订阅者获得更新后的状态。
3. **连接远程服务**：定义服务调用、发现和订阅的公共规则，由应用提供具体传输及路由。
4. **提供上下文和打包支持**：传递取消信号及调用级数据，支持插件 facet 打包、完整性检查和重新加载。

```text
chord/  # 插件组合、服务管理和状态同步组件
├── src/  # 公共接口及状态和服务源码
│   ├── context/  # 取消信号与调用上下文
│   ├── delta/  # JSON 状态变化跟踪及增量编码
│   ├── facets/  # 插件 facet 加载及生命周期管理
│   ├── node/  # Node 环境中的插件打包和加载
│   └── services/  # 服务提供、调用、订阅及状态同步
└── test/  # 服务、插件、上下文和状态变化测试
```

## 8. packages/durable 目录

`packages/durable` 是实验性的持久化 Agent 运行组件，基于 `ai` 调用模型、基于 `chord` 管理文档状态，支持进程重启后恢复工作。

1. **保存会话和状态**：通过原子提交记录对话、文档、输入和任务检查点，支持内存、JSONL 和 SQLite 存储。
2. **调度模型和工具任务**：管理生成、工具调用及后续轮次；重启后恢复未完成任务，并根据工具声明决定是否重放工具执行。
3. **管理多会话和子任务**：支持会话分支、子 Agent、任务图、取消、上下文压缩及用量统计。
4. **扩展运行行为**：通过注册表安装工具、指令、钩子和任务，将文件及命令操作委托给执行环境。

```text
durable/  # 持久化会话和任务运行组件
├── docs/  # 存储、任务和运行机制设计文档
├── src/  # 公共类型及持久化运行源码
│   ├── env/  # 文件和命令操作的执行环境接口
│   ├── harness/  # 模型生成、工具、调度和扩展注册
│   ├── session/  # 会话、原子提交、分支和订阅
│   ├── storage/  # 内存和持久化存储实现
│   │   ├── jsonl/  # JSONL 存储实现
│   │   └── sqlite/  # SQLite 存储实现及平台适配
│   ├── testing/  # 存储和执行环境的一致性测试辅助功能
│   └── tools/  # 读取、写入、编辑和命令执行工具
└── test/  # 运行恢复、任务、工具和存储测试
```

## 9. packages/protocol 目录

`packages/protocol` 定义实验性的 Pi 远程会话通信格式，供客户端和服务端共同使用。

1. **定义通信消息**：描述版本握手、请求、响应、取消、订阅更新和会话连接变化。
2. **标识请求目标**：使用服务端、会话及连接标识将消息关联到正确目标，校验消息结构和 JSON 载荷。
3. **编码字节消息**：提供 CBOR 编解码和长度前缀分帧，处理字节流中的消息分段与合并。

```text
protocol/  # 远程会话通信格式和编解码
├── src/  # 消息结构、校验和字节流分帧
│   └── cbor/  # CBOR 编码和解码实现
└── test/  # 协议、帧格式和输入校验测试
    └── cbor/  # CBOR 编解码测试
```

## 10. packages/server 目录

`packages/server` 是实验性的本地服务端组件，将客户端请求路由到应用提供的持久化会话和服务。

1. **接收客户端连接**：通过可替换的监听传输接收通信，并提供 Unix socket 实现。
2. **路由服务调用**：将服务端或会话范围的调用和订阅交给对应的应用服务，管理请求及返回消息。
3. **管理会话连接**：支持多个界面连接同一会话，校验连接标识并协调断开、订阅清理和服务端关闭。

```text
server/  # 客户端连接和会话服务路由组件
├── src/  # 连接、请求和会话路由源码
│   ├── testing/  # 服务端测试辅助功能
│   └── transports/  # 服务端监听及传输实现
│       └── unix/  # Unix socket 服务端传输
└── test/  # 连接、路由及会话生命周期测试
```

## 11. packages/client 目录

`packages/client` 是实验性 Pi 服务协议的客户端，供界面或其他应用调用服务端和远程会话。

1. **建立服务连接**：通过注入的字节传输连接服务端，检查版本和服务端身份，并提供 Unix socket 连接与发现功能。
2. **调用和订阅服务**：发送关联到服务端或会话的请求，接收响应及状态更新，并适配为 Chord 服务传输。
3. **管理连接状态**：维护当前会话连接目标，处理断开和待完成请求，提供由应用显式发起的重新连接。

```text
client/  # 远程会话服务调用客户端
├── src/  # 客户端、请求关联和传输适配源码
└── test/  # 连接、请求、订阅及断开行为测试
```

## 12. packages/env 目录

`packages/env` 为 `durable` 提供远程执行环境，让工具在另一台机器上操作文件和执行命令。

1. **提供统一执行环境**：将读取、写入、编辑、目录操作、文件监听和命令执行转发到远程机器。
2. **管理 SSH 连接**：检查主机身份，识别远程系统，部署并校验守护程序，再建立通信连接。
3. **运行远程守护程序**：由 Rust 程序通过 stdin/stdout 收发带长度信息的消息，执行远程操作并返回结果。

```text
env/  # 远程文件和命令执行环境
├── daemon/  # 运行在远程机器上的 Rust 守护程序
│   └── src/  # 文件操作、命令执行和通信源码
│       └── sys/  # Unix 和 Windows 系统适配
├── docs/  # 通信格式及执行语义说明
├── src/  # SSH 连接、部署和远程环境客户端
└── test/  # 环境一致性、守护程序和 SSH 测试
```

## 13. packages/telemetry 目录

`packages/telemetry` 提供通用运行观测接口，记录操作耗时、属性、事件和结果，供应用连接自己的观测系统。

1. **记录操作过程**：以显式上下文组织父子 span，记录属性、事件和成功或错误状态。
2. **定义观测数据类型**：通过可序列化 Schema 声明事件和属性，推导 TypeScript 类型并提供类型辅助接口。
3. **适配观测后端**：提供不记录数据的上下文、内存记录实现及适配器一致性检查，供应用接入日志或其他后端。

```text
telemetry/  # 运行观测接口和类型工具
├── src/  # span、上下文、Schema 和内存记录实现
│   └── testing/  # 观测适配器一致性检查
└── test/  # 类型、记录行为和适配器测试
```

## 14. packages/evals 目录

`packages/evals` 用于评估 Pi 编程 Agent 的行为，支持普通任务评估及提供文档前后的效果比较。

1. **定义评估任务**：使用 vitest-evals 组织任务场景、输入和评分规则。
2. **组织隔离运行**：支持本机评估，并通过 Docker 比较包含或不包含文档的运行结果，管理重复次数和任务计划。
3. **生成比较报告**：保存会话与观测数据，按配对任务统计得分、通过率和文档效果，并标记缺失或失败的运行。

```text
evals/  # 编程 Agent 行为评估
├── docker/  # 隔离评估所需的容器构建配置
├── evals/  # 任务场景、评分定义和评估输入
├── src/  # 评估运行、任务计划和报告生成
└── test/  # 评估运行器及结果统计测试
```
