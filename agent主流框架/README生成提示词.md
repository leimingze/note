# 学习目录 README 生成提示词（通用模板）

> 用途：把下方提示词中的 `{占位符}` 替换后发给 AI，即可为任意学习目录生成一份以「学什么、怎么学、学哪些」为主线的 README。

> 相关模板：生成 Jupyter 学习版 Notebook 请用 [Notebook生成提示词.md](Notebook生成提示词.md)。

## 使用方法

1. 复制下方提示词
2. 替换 `{主题}`、`{目录路径}`、`{日期}`、`{核验频率}`
3. 发送给 AI 后，先对齐结构再定稿
4. 定稿后把生成的 README 放回对应目录

## 提示词

```text
请为「{主题}」学习目录生成一份 README.md，保存在 {目录路径}。

README 必须围绕三条主线组织：
1. 学什么：明确学习目标与必学内容
2. 怎么学：给出可执行的学习方法、固定流程与学习顺序
3. 学哪些：列出需要学习的具体对象清单

必学内容必须覆盖：
- 市面上有哪些主流对象（框架、平台、工具或概念）
- 每个对象的特点
- 优缺点
- 局限性
- 如何选型（选型维度、决策方法、checklist）
- 每个对象的核心用法示例：可运行代码 + 按执行顺序拆解、带入具体输入，目标是带读者看懂机制
- 每个对象的核心能力逐个看：用可运行的最小例子覆盖该框架的核心特性（循环、并行、持久化、人工介入、流式、多 Agent 等，按框架实际情况取舍）

实时性要求：
- 顶部标注数据快照日期 {日期}
- 实时数据（星标、版本、维护状态等）注明来源
- 提供核验清单与更新频率（建议每 {核验频率} 个月）
- 保留修改记录表

输出要求：
- 使用中文，专有名词保留英文
- 使用表格呈现清单与对比
- 提供目录规划，方便后续逐步填充笔记与实践
- 如果产出 Jupyter Notebook：顶部先画该框架的流程图（节点用「英文名（中文名）」格式），核心概念之后用一条真实可运行例子串起概念关系
- 代码示例必须按执行顺序拆解并带入具体输入，先运行后拆解，目标是看懂机制而不是让读者手写
- 文件尽量少于 300 行
- 先与我对齐「学什么、怎么学、学哪些」的结构和必学清单，确认后再定稿
```

## 可调整项

- 必学对象数量：可增减，但建议保留「特点 / 优缺点 / 局限性 / 选型 / 核心用法示例 / 核心能力逐个看」六项要求
- 学习顺序：可换成自己的偏好
- 实时性：核验频率可按主题变化速度调整
