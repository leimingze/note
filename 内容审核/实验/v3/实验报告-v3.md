# 内容审核 v3 前置实验报告

2026-11-23。P1、P3、P4 通过。P2 中，当前挑帧器给出的事件数量与强度无法同时满足两项验收条件。实验 A、B、C 尚未运行。

## P1 · 哪些任务只因插帧标记被送审

从 v2 服务数据库导出最终一轮 E4 的 40 条连续发布任务（36588531 至 36588570）。5 条直接放行，14 条模型分数达到阈值，21 条低于阈值、仅因插帧标记送审。共有 32 条带插帧标记，其中 11 条同时达到模型阈值。5/40 与 v2 报告中的早退率一致。[逐条服务记录](../../../实习项目/PulseFrame/review-service/reports/v3/p1_gate.jsonl)

## P2 · 数量和强度的可行范围

从 CH-SV 中抽取 200 条时长不超过 20 秒的正常视频。按视频 ID 的 SHA-256 固定排序，排除 v2 训练、验证、三份测试清单及 E3 底片。200 个 ID 唯一，与 v2 五份清单交集为零。旧规则在该组命中 164/200（82%）。这个比例只衡量插帧规则触发。

v2 E3 原始记录有 15 个底片，每个底片有直接插入 1、3、10 帧，画中画，以及两种渐变强度。因此直接插帧和画中画共 60 条，含渐变共 90 条。设计中的 75 条缺少唯一对应的样本清单。本次分别核算两种范围。90 条视频重新提取的事件类型和帧序号均与 v2 匹配。Worker 重放 E3 全部 105 条（含 15 条原片），送审决定与 v2 送审清单逐条一致。[挑帧事件](../../../实习项目/PulseFrame/review-service/reports/v3/p2_events.jsonl) · [Worker 重放](../../../实习项目/PulseFrame/review-service/reports/v3/p2_baseline.json)

固定 M3 及其日常阈值，离线枚举 1,832 组规则。一次送审的条件为模型已达阈值，或事件数达到数量阈值，或至少一个事件达到强度阈值。正常组统计因插帧标记触发的条数。

| 验证样本 | 原规则送审 | 正常触发 ≤20/200 时最多送审 | 达到原送审数时最少正常触发 |
| --- | ---: | ---: | ---: |
| 直接插帧与画中画，60 条 | 59 | 56 | 83/200（41.5%） |
| 含渐变，90 条 | 89 | 72 | 120/200（60%） |

对 60 条中的 6 条视频，原规则送审且模型分数低于阈值。把三种事件分开，并将每种事件的强度按降序逐个比较，至少有 50 条正常视频在每一类上的事件数量和强度均达到其中一条的水平。任何随同类事件数量和强度增加而增加送审机会的确定性规则，若要保留这 6 条，就也必须送审这 50 条。原规则漏过的那条画中画视频没有任何规避帧，模型也低于阈值。含渐变时，对应下界为 69 条正常视频。两个下界均超过设计允许的 20 条。[阈值扫描及逐条对应关系](../../../实习项目/PulseFrame/review-service/reports/v3/p2_scan.json)

## P3 · 离线与 Worker 门控

按视频 ID 的 SHA-256 排序，从 v2 验证集取 50 条。离线读取 v2 的 FP16 特征缓存，用同一 M3 检查点打分。在线通过 Worker 的 `/risk_gate` 提交对应帧、标题、描述、OCR、ASR 及声音特征。沿用现行送审规则。最大绝对分差为 0.0007773，50/50 放行决定一致。这个结果覆盖当前 M3 门控接口。[逐条分数与决定](../../../实习项目/PulseFrame/review-service/reports/v3/p3_comparison.json)

## P4 · 同卡常驻

RTX 3090 的可用配置为 49,152 MiB。9B 与 3B 的 vLLM 显存配置比例分别为 0.55 和 0.25。两模型服务均返回模型信息，Worker 健康接口确认 ASR、OCR、CLIP、BGE、AST 和 M3 已加载。三者同卡时 GPU 占用 41,254 MiB，剩余 7,300 MiB。此处记录的是常驻快照，四并发峰值待实验 C 测量。[服务响应与显存记录](../../../实习项目/PulseFrame/review-service/reports/v3/p4_residency.txt)

## 后续实验的输入口径

KuaiMod 使用数据集提供的抽帧、标题、OCR 和 ASR。训练与验证共 1,015 条，其中 565 条为 KuaiMod。32 条、240 条、200 条三份测试集中分别有 21、175、100 条为 KuaiMod。其质量指标可按原样本标签评估，耗时从已有帧和文本进入审核开始计量。原片解码、重新挑帧、音轨分析及完整视频耗时使用 CH-SV。P2 需要引入数量和强度以外的判据，或调整验收目标，才能按设计进入后续实验。
