# 内容审核实验 v4

## 目的

实验 0 v3 的调参集为 298 条，留出集为 158 条。留出集正常误触率由 7.02% 上升到 13.82%，总体召回率由 78.33% 下降到 63.33%。v4 只扩大并配平实验 0 的评测样本，检查该差距是否来自小样本波动或阈值对新数据不稳定。

## 数据集

| 分区 | 条数 | 构成 |
| :--- | ---: | :--- |
| 调参集 | 298 | 228 条 CH-SV 正常 + 10 个合成底片 × 7 种版本 |
| 留出集 | 298 | 228 条 CH-SV 正常 + 10 个合成底片 × 7 种版本 |

合成底片沿用 v3 E3 的生成方式。前 15 个底片与 v3 一致，新增 5 个底片进入留出集。新增 105 条正常留出视频来自未进入既有训练、校准和三份测试集的 CH-SV 样本。

## 选优规则

- 检测阈值网格与 v3 相同；
- 最终验收要求正常误触不超过 20%、熔断误触为 0%、硬插召回为 100%；调参阶段使用 13% 误触预算，为留出集波动保留余量；
- 满足约束后优先最大化“硬插帧、画中画、渐变三类召回中的最低值”，再依次比较画中画与渐变召回、总体 F1、正常误触；
- 不重新训练实验 A 模型，不改动 v3 文件与结果。

检测阶段在基础事件上补采每个普通切镜前一帧，类型记为 `boundary_context`。它不进入规避误触统计，只增加候选帧；攻击命中允许它准确落在真实插入区间。这样可处理首个边界不明显、结束边界被识别为普通切镜的硬插帧。

原按总体 F1 选出的结果保留为 `exp0_v4_results_overall_f1.json`，均衡选优结果保留为 `exp0_v4_results_balanced.json`，用于和新规则对照。

## 正确性要求

每条攻击样本使用实际插入帧区间评测。渐变命中以完整叠加段为准，事件类型必须与攻击类型一致；缺少帧窗时直接报错。另用 v3 锁定阈值在两个新分区上原样复核，结果单独保存。

## 输出

服务器目录：`/root/autodl-tmp/rs-exp-v4/v4/`。

主要文件：

- `dataset_manifest.json`：596 条任务及攻击帧窗；
- `signals/`：原始检测信号缓存；
- `exp0_v4_results.json`：边界补帧、13% 误触预算和均衡召回选优后的结果；
- `exp0_v4_results_balanced.json`：仅改均衡选优时的结果；
- `exp0_v4_results_context_fpr20.json`、`exp0_v4_results_context_fpr15.json`：不同误触预算下的边界补帧结果；
- `exp0_v4_results_overall_f1.json`：按总体 F1 选优的原结果。
