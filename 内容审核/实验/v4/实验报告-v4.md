# 内容审核实验 v4 报告

2026-11-24。v4 在 v3 基础上扩大实验 0 的留出集、调整挑帧选优规则，并使用新的挑帧结果完成实验 A、B。实验 C 已启动但未完成。

## 结论摘要

- 实验 0：边界补帧明显改善了硬插帧和画中画覆盖。开发期留出集正常误触率 `17.98%`、硬插帧召回率 `100%`、总体召回率 `68.33%`。渐变召回仍只有 `25%`，且 13% 误触预算是在观察原留出集后确定的，该结果仍属于开发期复测。
- 实验 A：胜出模型由 v3 的 `A1-wide` 变为 `A2-wide`，三类宏平均 AUC `0.91901`，在 95% 违规召回时正常放行率 `37.89%`。
- 实验 B：三塔日常档违规召回率 `99.77%`、L3 召回率 `100%`、正常视频早退率 `18.86%`；严查档违规与 L3 召回率均为 `100%`，正常视频早退率 `11.25%`。
- 实验 C：未完成。最后可见进度为 S1 的 `Test-Full-240` 约 31 条，未生成五组汇总结果，不能给出实验 C 结论。

## 实验 0：挑帧规避检测

### 数据

| 分区 | 正常视频 | 合成底片 | 攻击版本 | 总数 |
| :--- | ---: | ---: | ---: | ---: |
| 调参集 | 228 | 10 | 70 | 298 |
| 留出集 | 228 | 10 | 70 | 298 |

前 15 个合成底片沿用 v3，新增 5 个底片进入留出集。攻击样本按真实插入帧窗评估，事件必须落在对应攻击区间。

### 选优方法

1. 在调参集扫描 432 组阈值。
2. 要求熔断误触率为 `0`、硬插帧召回率为 `100%`、正常误触率不超过 `13%`。
3. 满足门槛后优先最大化硬插帧、画中画、渐变三类召回中的最低值。
4. 对每个普通切镜补采边界前一帧，类型为 `boundary_context`。该帧不计入规避误触，只增加候选帧。

最终阈值：

| 参数 | 值 |
| :--- | ---: |
| `cut` | 0.15 |
| `fade` | 0.10 |
| `block` | 0.18 |
| `quiet` | 0.06 |
| `max_blocks` | 1 |
| `evasion_count` | 15 |
| `local_fade_peak` | 关闭 |

### 结果

| 指标 | 调参集 | 留出集 |
| :--- | ---: | ---: |
| 正常视频误触率 | 12.28% | 17.98% |
| 熔断误触率 | 0% | 0% |
| 硬插帧召回率 | 100% | 100% |
| 画中画召回率 | 80% | 60% |
| 渐变召回率 | 30% | 25% |
| 三类最低召回率 | 30% | 25% |
| 对抗样本总体召回率 | 73.33% | 68.33% |
| 精确率 | 58.67% | 48.81% |
| F1 | 65.19% | 56.94% |

留出集分类型召回：

| 类型 | 召回率 |
| :--- | ---: |
| 硬插 1 帧 | 100% |
| 硬插 3 帧 | 100% |
| 硬插 10 帧 | 100% |
| 画中画 | 60% |
| 30% 半透明渐变 | 10% |
| 50% 半透明渐变 | 40% |

### 对照

| 方案 | 留出集正常误触率 | 硬插召回率 | 总体召回率 | F1 |
| :--- | ---: | ---: | ---: | ---: |
| 总体 F1 选优 | 16.23% | 66.67% | 43.33% | 41.94% |
| 三类最低召回选优 | 25.88% | 66.67% | 50% | 39.74% |
| 边界补帧，13% 预算 | 17.98% | 100% | 68.33% | 56.94% |

### 判断

边界补帧解决了首个边界不明显、结束边界被识别成普通切镜的硬插帧漏检，使硬插帧召回率达到 `100%`。画中画仍有 `40%` 漏检，半透明渐变仍有 `75%` 漏检，当前检测仍不满足三类规避手段的生产要求。

## 实验 A：三塔门控模型选型

### 数据

| 项目 | 数量 |
| :--- | ---: |
| 固定交叉验证池 | 1,011 |
| 营销类样本 | 4 |
| CH-SV 宽训练增量 | 1,760 |
| 预留给实验 C 的压测视频 | 200 |

数据泄漏检查结果：训练、增量与三份测试集共比对 3,247 条记录，重叠为 `0`。

### 结果

最终候选排序：

| 模型 | 宽度 | 三类宏平均 AUC | ROC-AUC | 95% 召回时正常放行率 |
| :--- | :--- | ---: | ---: | ---: |
| A2 | wide | 0.91901 | 0.87273 | 37.89% |
| A3 | wide | 0.91651 | 0.87449 | 36.68% |
| A0 | medium | 0.85288 | 0.81099 | 35.29% |
| A1 | medium | 0.90952 | 0.84421 | 34.08% |

`A1-wide` 虽然 95% 召回时正常放行率达到 `41.2%`，但 KuaiMod 三类宏平均 AUC 下降 `0.01106`，超过允许的 `0.01`，因此未入选。

`A2-wide` 分类别 AUC：

| 类别 | AUC |
| :--- | ---: |
| 色情与低俗 | 0.95214 |
| 暴力与危险行为 | 0.95568 |
| 言论与攻击 | 0.84920 |

`A2-wide` 跨平台结果：

| 训练与测试方向 | 三类宏平均 AUC |
| :--- | ---: |
| KuaiMod → CH-SV | 0.75839 |
| CH-SV 中量 → KuaiMod | 0.79540 |
| CH-SV 宽量 → KuaiMod | 0.81944 |

融合对照中，三路取最高分在 95% 召回时正常放行率为 `37.89%`，三路拼接为 `42.04%`。当前选型仍保留三路取最高分，避免跨模态风险被拼接特征稀释。

### 判断

`A2-wide` 的三类宏平均 AUC 比 v3 的 `A1-wide` 高 `0.00295`。相对零样本 A0 高 `0.06613`，说明训练门控有明确收益。

原始结果见 [exp_a_train_results.json](../../../实习项目/PulseFrame/review-service/reports/v4/exp_a_train_results.json)。

## 总体结论

1. 实验 0 的边界补帧是有效的工程改进，解决了硬插帧首个边界不明显时的漏检。
2. 当前像素信号仍无法可靠识别半透明渐变，新增画面判据是后续优先级最高的工作。
3. `A2-wide` 明显优于零样本 A0，并略优于 v3 的 A1-wide。
4. 四类独立阈值相对统一阈值有明显放行收益，但日常档在本轮数据上仅放行 `18.86%` 正常视频，与训练阶段 37.89% 存在差距，阈值迁移仍需关注。
5. 实验 C 未完成，当前不能判断哪种生产方案最终胜出。
